# MacroHUB

Макросы для Roblox-игр **Jujutsu Shenanigans** и **Jump Showdown**.
Небольшое меню поверх окна игры: включил нужный мод — и играешь как обычно,
программа сама жмёт клавиши в нужные моменты.

## Моды (Jujutsu Shenanigans)

| Мод | Что делает | Клавиша |
|---|---|---|
| **Black Flash** | Жмёт «3» → пауза → ещё раз «3» | E |
| **Todo** | Комбо для Todo: серия нажатий подряд | E |
| **Off** | Ничего не делает — E уходит в игру как есть | — |
| **Авто QTE** | Пока держишь **F1** — сам жмёт A/W/D, когда на экране появляются стрелки | F1 (держать) |

**Auto Mod** (включён по умолчанию) сам выбирает режим: узнаёт персонажа
по полоске имени и включает Black Flash или Todo. Любой другой персонаж —
ставит Off, чтобы макросы не мешали. В меню видно, кого он сейчас видит
(«поиск...» / «Black Flash» / «Todo» / «другой персонаж»).

## Jump Showdown

**Авто 4** — следит за экраном и в нужный
момент сам жмёт «4» (с небольшой паузой между нажатиями). Работает
автоматически, включается переключателем в меню. Больше ничего не жмёт.

## Кнопки и клавиши

| Действие | Где |
|---|---|
| Включить/выключить макрос режима | клавиша **E** |
| Авто QTE | держать **F1** |
| Скрыть/показать меню | **F6** или синяя кнопка [F6] в шапке |
| Выход из программы | **F7** или красная кнопка [×] в шапке |

В самом меню: «Статус» — общее включение/выключение всех макросов,
переключатели Auto Mod и «Авто 4», выбор режима (Off / Black Flash / Todo),
строка с ID (клик — копирует в буфер обмена).

## Общее

- **Игра определяется сама** по логам Roblox. Неизвестная игра — все
  макросы молча выключены, клавиши проходят в игру как есть.
- **Автообновление**: при запуске программа проверяет версию и сама
  обновляется, если вышла новая.
- Меню всегда поверх окна, перетаскивается за шапку, масштабируется
  под разрешение экрана, нажатия озвучиваются.
- Доступ по ID машины. Нет доступа — программа покажет твой ID
  (клик по нему копирует). За доступом: Telegram **@PerfectosOff**.

## Запуск

1. Запусти `MacroHUB.exe`.
2. Зайди в игру — в меню напротив «Плейс» появится её название.
3. Выбери мод (или оставь Auto Mod) — играй.
